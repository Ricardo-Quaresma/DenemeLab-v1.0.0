1. Şu linke git: https://aistudio.google.com/apikey

2. Google hesabınla giriş yap

3. "Create API Key" butonuna tıkla

4. Yeni bir Google Cloud projesi seç veya oluştur

5. API Key'i kopyala

6. TestAI → Ayarlar → Yapay Zeka Ayarları → Yapıştır → Kaydet

ÇÖZÜM:

✅ Seçenek 1: Bekle ve Tekrar Dene (Önerilen)
   → 5-10 dakika bekle
   → Tekrar analiz başlat
   → Uygulama otomatik 3 kez dener (5-11-17 sn aralıkla)

✅ Seçenek 2: Farklı Model Dene
   → Ayarlar → Yapay Zeka Ayarları → AI Modeli
   → "Modelleri Yenile" butonuna tıkla
   → Farklı bir model seç (örn: gemini-1.5-pro)

✅ Seçenek 3: Farklı Saatte Dene
   → Yoğun saatler: 09:00-18:00 (iş saatleri)
   → Sakin saatler: 22:00-08:00 (gece)
   → Hafta sonları genelde daha az yoğun

Google Gemini API ücretsiz kotası:

gemini-1.5-flash:
• 15 istek / dakika
• 1,500 istek / gün
• ~50 test analizi / gün

gemini-1.5-pro:
• 2 istek / dakika
• 50 istek / gün
• ~15 test analizi / gün

ÖNEMLİ:
• Kota her gece sıfırlanır (UTC 00:00)
• Ücretsiz kullanım için kredi kartı gerekmez
• Kotayı aşarsan 429 hatası alırsın

  🔧 DİĞER HATA MESAJLARI
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ 400 Bad Request / Invalid API Key
   → API Key yanlış
   → Ayarlar → API Key kontrol et
   → Tekrar kaydet

❌ 403 Forbidden
   → API Key yetkisi yok
   → Google Cloud'da API aktif mi kontrol et
   → Yeni API Key al

❌ 429 Too Many Requests
   → Günlük kotanı aştın
   → Yarın tekrar dene
   → Veya ücretli plana geç

❌ 404 Model Not Found
   → Model ismi yanlış
   → Ayarlar → Modelleri Yenile
   → Geçerli model seç
